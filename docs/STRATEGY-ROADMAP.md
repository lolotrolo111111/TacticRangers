# Roadmap: strategic interface

## Direction

The current text-based planet command screen remains available for precise
micro-management and debugging. It is not the intended main way to run the
Coalition.

## Next interface milestone

Create a sector-level command layer that lets the player see the condition of
all controlled systems at once and give common orders without opening each
planet individually. The camera dossiers are the visual reconnaissance layer;
the future sector screen is the operational layer.

Planned data on that screen:

- system threat and Dominator presence;
- population, budget and economy of its planets;
- stationed and travelling fleets;
- alerts and quick defensive/economic orders.
