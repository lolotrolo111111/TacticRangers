# Отладочные команды стратегической кампании

Команды вводятся прямо во время игры, без поля ввода и без паузы.
Они предназначены для тестовых сохранений: часть из них меняет время кампании
или создаёт корабли.

| Команда | Действие |
| --- | --- |
| `STRATINFO` | Показывает текущий день, год, фазу, уровень Доминаторов и их состояние. |
| `STRATYEAR` | Перемещает кампанию на один год вперёд. |
| `STRAT5` | Устанавливает пятый год кампании. |
| `STRAT10` | Устанавливает десятый год кампании. |
| `STRATSPAWN` | Создаёт обычного тестового Доминатора в текущей системе. |
| `STRATBREAK` | Ломает всё оборудование первого Доминатора в текущей системе. |
| `STRATTANK` | Создаёт рядом с игроком тестового Доминатора: 10 000 HP корпуса, ремонт 1 000 HP, без оружия и генератора защиты. |
| `STRATGEAR` | Показывает число модулей, диапазон прочности и число поломок у первого Доминатора в текущей системе. |

## Условия

`STRATINFO`, `STRATYEAR`, `STRAT5` и `STRAT10` относятся к стратегической
кампании 500%. Команды создания кораблей требуют, чтобы игрок находился в
системе с планетой.

В стратегической кампании 500% Доминаторы получают износ всего установленного
оборудования при каждом полученном боевом попадании. В оригинальной игре эта
ветка износа для них была отключена.
